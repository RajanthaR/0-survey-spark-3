# Prompt 2.5 — CSP nonce on `script-src` (drop `'unsafe-inline'`)

**Goal:** Replace the inline pre-hydration `<script>` with a
server-rendered `<html lang>` driven by a cookie, then move
`script-src` and `script-src-elem` from `'unsafe-inline'` to a
per-request nonce. `style-src` stays on `'unsafe-inline'` for now
(deferred — see `09-deferred-breaking.md` D-11).

**Audit ref:** `audits/13-codex-parity-supplement.md` S-16, `audits/08-i18n.md` I-4.

**Depends on:** 2.1 and 2.3 merged (both also touch `src/start.ts`).

## TODO

1. Read first:
   - `src/routes/__root.tsx:80-145` (CSP meta + the inline language
     pre-hydration `<script>`)
   - `src/start.ts`
   - `src/server.ts` (Cloudflare entry)
   - `src/lib/i18n.tsx` (current language read path)
2. **Replace the inline pre-hydration script** with a cookie-driven
   server-rendered `<html lang>`:
   - On the server side, read `cookies.get("lang")` (or whatever the
     existing convention is); default to `"en"`.
   - Render `<html lang={lang}>` directly in `__root.tsx`'s `<Html>`
     wrapper.
   - Remove the inline `<script>` that previously wrote
     `document.documentElement.lang`.
   - On every language toggle, the client sets `document.cookie =
     "lang=...; path=/; max-age=31536000; samesite=lax"` so the next
     SSR render matches.
3. **Add a per-request nonce** in `src/server.ts` (Cloudflare entry):
   - Generate a 16-byte random base64 string per request.
   - Inject it into the CSP header **and** into every `<script>`
     emitted by TanStack Start's `<Scripts />`.
   - If TanStack Start does not yet expose a `nonce` prop on
     `<Scripts />` in the installed version, STOP and defer 2.5 to
     `09-deferred-breaking.md` D-11 — note the version that *would*
     support it.
4. **Update the CSP**: instead of meta tag, deliver via response
   header in `src/server.ts` (so the nonce can vary per request).
   - `script-src 'self' 'nonce-XYZ' https://challenges.cloudflare.com`
   - `script-src-elem 'self' 'nonce-XYZ' https://challenges.cloudflare.com`
   - Keep `style-src 'self' 'unsafe-inline' https://fonts.googleapis.com`
     (deferred).
   - Keep the existing `frame-src`, `connect-src`, `img-src`, etc.
   - Remove the `<meta http-equiv="Content-Security-Policy">` from
     `__root.tsx` once the header is in place.
5. **Roll out as report-only first**: also send
   `Content-Security-Policy-Report-Only` alongside the enforcing
   header for one week. Document the cutover date in the PR body.
