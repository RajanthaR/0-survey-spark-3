## TODO

1. Read first:
   - `package.json`
   - `.husky/` if it exists
2. Add dev dependencies:
   ```bash
   bun add -d husky lint-staged
   ```
3. Initialise husky:
   ```bash
   bunx --bun husky init
   ```
   Replace the generated `.husky/pre-commit` body with:
   ```sh
   #!/usr/bin/env sh
   bunx --bun lint-staged
   ```
   Make it executable: `chmod +x .husky/pre-commit`.
4. Add a `lint-staged` block to `package.json`:
   ```json
   "lint-staged": {
     "*.{ts,tsx}": [
       "eslint --max-warnings 0",
       "prettier --check"
     ],
     "*.{js,mjs,cjs,json,md,css,html}": [
       "prettier --check"
     ]
   }
   ```
5. Add a `prepare` script to `package.json` so fresh clones install
   hooks: `"prepare": "husky"`.
6. Add a one-paragraph section to `docs/TROUBLESHOOTING.md` explaining
   how to bypass the hook for legitimate WIP commits:
   `git commit --no-verify -m "wip"`.

## Verification

```bash
# A clean staged file commits without friction:
echo "// test" >> README.md
git add README.md && git commit -m "test: pre-commit clean" && git reset HEAD~1
git checkout README.md

# A staged file with prettier issues fails the hook:
printf "const  x =1;\n" > /tmp/probe.ts
mv /tmp/probe.ts src/probe.ts
git add src/probe.ts
git commit -m "test: should fail" || echo "OK: hook blocked the commit"
git restore --staged src/probe.ts && rm src/probe.ts
```
