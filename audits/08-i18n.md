# Audit 08 — i18n (EN / SI / TA)

## Strengths
- `pickText` falls back to EN; Noto Sans Sinhala/Tamil via `:lang(si/ta)`.
- ESLint guardrail rejects inline SI/TA outside dictionaries.
- Survey parity: 168/168/168 (phase-1), 195/195/195 (phase-3).

## Findings
- **I-1** UI dictionary drift: 67 EN / 66 SI / 66 TA in `i18n.tsx` (one missing).
- **I-2** 5 inline SI/TA literals: `SurveyRunner.tsx:517`, `ResponseVisualSummary.tsx:19`, `analytics-report-i18n.ts:40`, `exports-extended.ts:79`, `admin.tsx:2468`.
- **I-3** Stale doc comments in `phase-1.ts:7` and `phase-3.ts:7` say "TA = TODO" but Tamil is fully populated.
- **I-4** SSR `<html lang>` hard-coded to `"en"`; only fixed post-hydration by inline script.
- **I-5** 404 / 500 / "Survey not found" pages are English-only.
- **I-6** Researcher-login CTA on `/` is English-only.
- **I-7** Likert `aria-label` uses just `"1"`–`"5"`; not localised.
- **I-8** Tamil reviewer attribution missing from README.

## Suggested fixes
1. Fix dictionary drift; add a unit test asserting key parity across en/si/ta.
2. Move the 5 inline literals to dictionaries.
3. Update doc comments; add reviewer + review-date.
4. Emit correct `<html lang>` on the SSR first byte (cookie/hint).
5. Localise error pages and the researcher CTA.
6. Richer Likert `aria-label` (`"5: Strongly agree"`).
